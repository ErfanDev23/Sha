# آکادمی زیست‌شناسی دکتر علیرضا احمدیان

نسخه کامل فرانت‌اند + بک‌اند پروژه.

## اجرا
1. Node.js 18 یا بالاتر نصب باشد.
2. `.env.example` را به `.env` کپی کنید و `ADMIN_PASSWORD` را عوض کنید.
3. `npm start`
4. مرورگر: `http://localhost:3000`

## امکانات بک‌اند
- ثبت‌نام و ورود امن با هش رمز عبور
- نشست Bearer Token
- کاربران و پروفایل
- دوره‌ها، ویدیوها، PDFها، آزمون‌ها، وبلاگ، FAQ، پیام‌ها و کوپن‌ها
- سفارش و محاسبه قیمت در سمت سرور
- مدیریت state توسط ادمین
- آمار، کاربران، سفارش‌ها و export
- ذخیره دائمی در `data/db.json`

## نکته پرداخت
ثبت سفارش و وضعیت `pending` در بک‌اند فعال است، اما اتصال به درگاه واقعی نیاز به merchant credentials و قرارداد درگاه دارد؛ این بخش عمداً بدون کلید واقعی تحویل شده است.

## امنیت
رمز پیش‌فرض فقط از environment ساخته می‌شود. حتماً قبل از انتشار `ADMIN_PASSWORD` را تغییر دهید و پروژه را پشت HTTPS قرار دهید.
